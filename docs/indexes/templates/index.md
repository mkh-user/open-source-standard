# Templates

This section provides copy-pasteable skeletons implemented based on each standard.

!!! Note
    Some standards are not applicable to provide a template. See [:lucide-book-text: Guides](../guides/) for these standards to learn to implement them.

In a template you can see:

- One or more code blocks that you can copy-paste.
- A **How to Fill This Template** section containing the meaning of each placeholder.

[:lucide-book-text: Guides section](../guides/) provides practical, step-by-step tutorials that explain how to apply each standard from scratch. Specification of each standard is available in [:lucide-clipboard-list: Specs section](../specs/) for full philosophical and technical details.
