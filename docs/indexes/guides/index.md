# Guides

This section provides practical, step-by-step tutorials that explain how to apply each standard from scratch.

In each guide, you can find these sections:

- **Prerequisites:** Any prior knowledge or tools required, linked to primary sources got get ready.
- **Step-by-Step Instructions:** Steps to apply standard (e.g., `### Create the directory...`, `### Write the spec file...`).
- **Checklist:** A summary checklist to verify completion.

Templates that can be filled to apply a standard more faster and with less details are available in [:lucide-book-dashed: Templates section](../templates/). Specification of each standard is available in [:lucide-clipboard-list: Specs section](../specs/) for full philosophical and technical details.
