# Specifications

This section provides authoritative reference documents containing all rules, requirements, and rationale. Specifications are the "source of truth."

In each specification, you can find these sections:

- **Core Statement:** Concise description of the standard's purpose.
- **Rationale & Constraints:** Explanation of why the standard exists and its limitations.
- **Technical Details:** Comprehensive list of requirements, rules, and implementation details.
- **Examples:** (Optional) Concrete examples of the standard in practice.
- **Exceptions:** (Optional) Conditions under which the standard may be ignored.

[:lucide-book-text: Guides section](../guides/) provides practical, step-by-step tutorials that explain how to apply each standard from scratch. Templates that can be filled to apply a standard more faster and with less details are available in [:lucide-book-dashed: Templates section](../templates/).
